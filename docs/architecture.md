# System Architecture

## Overview

The IT Asset Management System is a web-based application designed to manage company IT assets.

## Architecture

The initial architecture consists of:

Browser
↓
PHP Application
↓
MySQL Database

## Backend

PHP is used for server-side application logic.

## Database

MySQL is used as the relational database management system.

## Frontend

HTML, CSS, and JavaScript are used for the user interface.

## Main Components

- Authentication
- Dashboard
- Employee Management
- Asset Management
- Asset Assignment
- Maintenance Management
- Reporting

## Development Approach

The project is developed incrementally using Git feature branches and GitHub Pull Requests.
